## Agent controls / ACS review

Reviewed official [ACS repository](https://github.com/GenAI-Security-Project/agent-control-standard)
and [OWASP 2026 list](https://github.com/GenAI-Security-Project/GenAI-LLM-Top10/blob/main/2026/README.md).
Our native controls inspect an intent before dispatch, compile server-owned
arguments, authenticate signed contexts, fail closed on invalid output, fence
duplicate execution and preserve metadata correlation. Post-read authorization
and source freshness are rechecked before release; cancellation/unknown outcomes
are explicit. These implement relevant enforcement concepts independently of
model instructions. An ACS Guardian/wire adapter and formal conformance tests are
**not implemented**; there is no ACS certification/interoperability claim.
