## Failure taxonomy and measured remediation

1. **Insufficient unseen header coverage:** rule abstains on all 12 test cases;
   model exact mapping is only 2/10. Preserve manual review, seeded rules and
   Java authoritative validation. Do not add test aliases or tune prompts on
   these answers and then call a repeated score held-out quality.
2. **Sentence-boundary false rejection (`q13-01`):** Qwen returned the correct
   full English receipt sentence. The validator merged it with following Japanese
   text because it only recognized a Latin/numeric next sentence. A focused test
   failed before the fix. Recognizing Japanese/CJK sentence starts after period
   plus whitespace now allows the recorded quote; replay test passes without new
   inference. Existing whole-sentence/qualifier-negative tests remain passing.
   The archived run stays at 6/8, never retrospectively changed to 7/8.
3. **Malformed abstention (`q13-08`):** Qwen selected conflict but included claims,
   violating the fixed Proposal invariant. Validation rejected it. Retain this
   failure; production has a separate early conflict guard and stricter decoding.
4. **Proxy blind spot:** earlier signed QA passed anchors while including an
   extra Japanese approval sentence. Semantic relevance needs genuine reviewer
   assessment; anchor matching alone is insufficient for quality acceptance.
5. **Rerank regression:** fixed lexical overlap degraded dev rank quality.
   Keep `reranker=none`; preserve negative/unchanged results.
