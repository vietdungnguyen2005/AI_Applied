## Failures and corrections retained

The initial integrated Docker attempt used an internal bridge and hit a host
readiness deadline on Docker Desktop; a dedicated bridge resolved host forwarding.
That network change is disclosed, not relabeled egress isolation. An initial DB
outage hit the client's timeout while DB/DNS work lingered. A focused test failed
before the readiness fix: one in-flight DB probe is now reused, response budget
is one second, late expected exceptions are sanitized, and repeated probes do not
spawn unbounded waiting threads. The final actual outage returns503/trace rather
than hanging. Initial helper lint errors and an expected unsigned-status mismatch
(401, not403) were corrected before final verification. Earlier unsuccessful
private logs remain under `.local`; no missing success transcript was invented.

## Monitoring, maintenance and delivery limits

`tools/ops_probe.py` measures request errors, latency and correlation without
application data/model calls. `tools/ops_report.py` projects retained benchmark
errors, quality proxies, tokens and returned costs; missing costs remain null.
Tool failure rates require actual tool observation rows; first-intent plans are
not executed tools. Retrieval quality is retained in P13's scored summaries.
There is no centralized telemetry store or installed OpenTelemetry stack.

CI covers lint/type/tests/contracts/dataset/eval verification, SQL migration and
real PG permissions, Compose config and image build. Integrated Project2/browser
drills are explicit opt-in local commands, not falsely claimed remote CI jobs.
Runbook guidance for bad indexes, dimensions, profiles, roles, runaway cost,
provider disable and rollback references tested mechanisms; only the stopped
DB/AI services above are actual outage drills. No destructive schema downgrade or
provider-ledger reset was performed. Unknown live reservation remains blocked.

All owned integrated containers/processes were cleaned. Standalone test resources
are stopped after final verification, with volumes retained for inspection.
