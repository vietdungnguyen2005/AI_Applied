Use `make lint typecheck test contracts dataset-check retrieval-eval-check
mapping-eval-check`; these are frozen regression checks, not fresh held-out tests.

`python -m uv run --frozen python tools/p12_model_smoke.py` reproduces the labelled
single-source local-model functional check.
