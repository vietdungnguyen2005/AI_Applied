## Delivered scope and acceptance limits

GET `/ai/citations/{chunk_id}` rechecks current source, effective dates and grants. Default routes remain health/readiness only; signed integrated identity remains disabled until P09. Question → P06-selected dense retrieval → bounded untrusted-source context → JSON-schema constrained model proposal → exact quote and fresh-current-citation validation. Server answers contain only verified source quotes; no model paraphrase, arbitrary URL or tool action escapes. Confidence low/unknown is explicitly uncalibrated. Literal quote provenance is not an independent semantic relevance/NLI judgment. ## Actual development measurements, failures retained

[Original four-case baseline/RAG probe](../../evals/qa/runs/live-v1/predictions.jsonl) stopped after a provider failure. First English RAG output was valid JSON with two complete contiguous source sentences, but the initial validator incorrectly permitted only one sentence. The corrected validator accepts contiguous complete spans while still rejecting skipped qualifiers, truncation and modified quotes. The original 502 is retained, not rewritten as success.

Another fresh software-verification output still failed validation. A structured-output attempt produced a valid abstention to the positive question. Inspection found missing authoritative context: the question used RIVERBYTE while sources said Supplier B. Final context supplies the fixed corpus's vendor/alias mapping; output requests explicitly use JSON Schema with allowed chunk/quote enums, required parameter support and reasoning disabled. These are development changes, not tuning on P06's consumed holdout.

The final smoke answered both positive questions with verified quotes: **2/2 positive anchor proxies, two quote-supported answers, two citation opens**. It used actual routed free models (`nvidia/nemotron-3.5-super-vl:free` and `dots-studio/dots-3-note-preview:free`), recorded in the transcript. Unknown-tax returned 503/provider failure and is not counted as correct abstention. The final conflict case was skipped after stopping; the real-retrieval/fake-chat demo separately verifies that deterministic pre-chat guard.

The completed prompt-only baseline abstained on its one English positive: **0/1 positive anchor passes, zero citations**. Its other cases were not completed. These unequal denominators, different routed models and changing development code do not prove a causal retrieval accuracy improvement. Human semantic factual accuracy and citation relevance remain NOT RUN. [Summary](P07-evaluation-summary.json) and [QA eval inventory](../../evals/qa/README.md) keep those limits explicit.

Earlier interim lint/types found long literal lines and a provider-protocol annotation; they were corrected. The first source commit retained one lint-only long baseline line, fixed in the next pre-probe commit. Initial diagnostics and [interim tests](logs/P07-qa-interim.log) are retained; no reconstructed raw failure log is fabricated.
