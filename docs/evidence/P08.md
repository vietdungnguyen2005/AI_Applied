## Results, failures and selection

[Three retained comparisons](../../evals/mapping/README.md) each ran 38 known train/dev/regression cases through both methods. Eight train/six dev/24 regression; 26 mapping-labeled cases, 12 no-mapping negatives. Twelve mapping test cases received no inference; fixtures/labels were available during development, so this is not blind human gold evaluation.

| Method | Exact /26 | Coverage | Required-field edit proxy | Abstained /38 | Input errors /38 |
| --- | --- | --- | --- | --- | --- |
| Exact seed/train-only rules | 20 | 76.9% | 18 | 7 | 10 |
| Initial 4B | 3 | 60.3% | 31 | 5 | 10 |
| Clarified 4B | 19 | 73.1% | 21 | 9 | 10 |
| Same clarified prompt, 9B | 16 | 61.5% | 30 | 11 | 10 |

Default method is **rule**, optional local model remains **4B**. Neither model surpassed the baseline overall. Initial prompt repeatedly omitted stock headers; [train-only diagnostic](P08-train-diagnostic.json) showed typed null/string schema alone did not fix the two seed probes, while clarifying column selection versus stock-value generation did. Initial 76 outputs remain, not overwritten. The clarified 4B still succeeds on only 1/6 dev cases; no reliable unseen supplier accuracy, productivity benefit or customer-ready automation is claimed. Model generation and rule comparison differ by intended method, so the prompt iteration is not a controlled causal experiment.

Clarified 4B rejects one model response as invalid and emits a safe abstention; original raw model text is not retained, so its exact invalid subtype is not asserted. All final service predictions/error states are retained. API failures/rejections are not counted as correct mappings. Zero structural invalid published drafts does not mean zero semantic errors. Negative missing-header fixture gives an incomplete rule draft (and a 9B partial draft), which differs from its provisional input_error label. Inactive fixture metadata is not allowed to override the server's seed policy; explicit inactive policy is tested separately. Unknown catalog SKU/vendor mismatch/freshness conditions remain Java validation, not inferred from labels.

Edit counts are automated field-comparison proxies, not observed human edits. Actual human acceptance/edit/time and semantic/provenance-relevance review are NOT RUN. CIs validate saved evidence without a GPU/model download or external provider request. Reports pin full model digests, runtime, LF-normalized source hashes, label and prediction hashes. Historical source commit hashing permits later phases without rewriting these results. Source/default-method change after comparison does not affect the runner's explicit method selection.

Initial intermediate lint/style and a missing test-helper import were corrected; the first target run passed 29 tests before the final negatives were added. A Windows encoding helper failed reading Japanese with the OS default encoding and was rerun with UTF-8; no artifact was silently modified to mask it. Initial/updated targeted/full logs and all three development runs are retained. No raw missing failure transcript is fabricated.
